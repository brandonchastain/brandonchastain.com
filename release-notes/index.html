brandonchastain/rss-reader

  • Login now goes through the API. The site cut over to API login with Microsoft on 2026-10-17, with Google and GitHub providers built behind it. Admin access and Microsoft account linking were fixed along the way, and the provider account picker always appears.
  • Deploys no longer risk losing recent writes. The database is handed over between revisions, which ends the risk of losing up to 15 minutes of user writes on each deploy.
  • Cost and cold starts: the API keeps one replica warm, and idle backup, scheduler, and probe work was cut to bring the bill back down from about $45/month.
  • Timeline: read posts stay visible until the next fetch, the misleading "new posts" toast no longer appears on search or per-feed pages, and manual refresh fetches every stale feed. The list no longer shifts while you read, and the cached timeline reconciles with the server on open.
  • The API has its own hostname, api.rss.brandonchastain.com, and self-hosting docs were added. Production was deployed 20 times.

brandonchastain/shipped-log

  • Sends a notification via ntfy, using the same topic and optional token setup as the cost watchdog.
  • A setup.ps1 script stores the workflow secrets with gh so they never end up in the repo.
