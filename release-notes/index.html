brandonchastain/rss-reader

New features

  • Headlines open the post in the reader in place; ctrl/cmd-click or middle-click still opens the original.
  • Post lists take vim keys: j and k move, l opens, h closes, m marks read, and ? lists them all.
  • The [Aa] control sets the body font (mono, serif or sans) and size from 80% to 160%, remembered in this browser.

Improvements

  • Excerpt-only posts link to the original from the foot of the reader, where they used to end.
  • The sign-in screen names Microsoft and says the app works on phone and desktop.

Performance

  • The API fits 0.25 vCPU and 0.5 GiB, the smallest always-on size, after the move to .NET 10 and a 32 MB cap on caches.
  • Refreshes no longer cache the content of every post, so only posts someone opens are cached.

Reliability

  • An anonymous feed-freshness endpoint reports how long ago the newest post was stored, so a silent feed stall can alert.
  • Replica compaction had stalled for 26 hours, so the stuck levels are removed until a fixed Litestream ships; restores are unchanged.
  • Replica history is kept three hours instead of a day, cutting replica storage from 8.7 GB to an expected 0.9 to 1.4 GB, at the cost of a restore window of three to four hours.

Fixes

  • NASA's APOD feed at its new address parses again; a missing space in its root tag had broken it.
  • Collapsing a post no longer marks it read, so mark unread sticks while the post stays open.
  • Around 1024px the toolbar no longer overlaps the nav links; Privacy moves to Account.

Infrastructure

  • Storage accepts only the app's managed identity, so account keys and key-signed links stop working; laptop az storage calls need --auth-mode login.
  • The unused read-replica app is removed, leaving the writer as the only app.

brandonchastain/vitals

New features

  • One binary runs as the server, with the API, scheduler and dashboard, or as an agent that pushes its checks.
  • A UPS check is amber on battery or low runtime, and red when NUT cannot see the UPS, since nothing then shuts the NAS down cleanly.

Improvements

  • Each component gets one tile wherever its checks run, naming the hosts that report it.
  • A check can name the tile it depends on; while that tile is down, its dependents show unreachable rather than red.
  • The refresh toggle (1 s, 5 s, 30 s or off) swaps the page content in place and is remembered per browser.

Reliability

  • An agent counts as gone after 2.5 times its fastest reporting gap, so one outage no longer turns three tiles three colours.

Fixes

  • The Pi agent's service starts again; an inline comment in its systemd unit had stopped it.

Infrastructure

  • SNMP is removed; the NAS agent reads its memory and swap directly, so no SNMP user or password is kept.

brandonchastain/rss-reader

New features

  • The Feeds page is a hub of cards: My feeds with a count, Popular feeds, Subscribe, Import / Export and Tags, each opening its own page.
  • A feed that fails three times in a row shows a "not updating" badge, with the reason and the last attempt in its row.

Improvements

  • Each post is stored once per feed, not once per subscriber, and unsaved posts older than 180 days are deleted nightly.

Performance

  • Scheduled refreshes now pace their fetches. At 5 a second, p95 under 50 req/s fell from 513 ms to 30 ms, at the cost of a 5,000-feed cycle taking 999 s instead of 80 s.
  • Search answers from the full-text index: a rare word returns in 17 to 20 ms, down from 109 to 216 ms, at the cost of no longer matching words that start mid-word, such as "flare" in "cloudflare".

Reliability

  • Deploys no longer return 5xx on /api/user: the CI probe saw none over 61 samples on the deploy that followed the handover fix.
  • A failed restore at startup restarts the app and retries, so an empty replica never replaces your database.

Fixes

  • Sign-in now survives closing the browser, so a return visit no longer starts at the login button.

brandonchastain/brandonchastain.com

  • Added a weekly Release Notes page at /release-notes/ (renamed from /shipped/), linked from the home page. A Sunday-evening bot summarizes the week's commits, merged PRs and releases across my repos and commits the result to master so the site deploys. The first week (2026-W42) is seeded from a real run, and the fallback summary is kept short with the raw list in a collapsible block.

brandonchastain/rss-reader

  • Moved login off Static Web Apps Easy Auth and into the API, with Google, Microsoft and GitHub providers behind /auth/*. The cutover on 2026-10-17 made Microsoft login go through the API, and the Functions proxy is retired. Existing accounts are linked by a hash of the Microsoft-reported email, the admin checks work after the migration, and the account picker always appears.
  • Deploys no longer lose user writes. The new revision hands the database over from the old one before it starts, which closes a window of up to 15 minutes of lost writes on every deploy.
  • Kept one replica warm to fix a 45.6s cold start that ended in a 500, and cut idle-time work (backups, scheduler, probes) to bring the bill back down.
  • Timeline and read state fixes: the cached timeline reconciles with the server on every open, the list no longer jumps under the reader while paging, the "new posts" toast works on first load and stays off Search and per-feed pages, read posts stay visible until the next fetch, and a post stays read after Back from an outbound link. Manual refresh now fetches every stale feed.
  • Added self-hosting, architecture and knobs docs for the API, with 20 production deployments this week.
